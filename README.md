## Summary
Menu AI Digital Dining & Nutrition Platform — smart digital menu creator, allergen detection system, nutritional analysis, and dynamic pricing optimizer.

## Core Features
*   **Interactive Digital Menu Builder:** Create engaging and visually appealing menus.
*   **AI Nutrition & Macro Breakdown:** Automatically analyze and display nutritional information.
*   **Automated Allergen Tagging:** Keep customers safe with smart allergen detection.
*   **Dynamic Price Recommendation Engine:** Optimize your pricing strategy using AI insights.

## Setup Guide
1. Install dependencies:
   ```bash
   npm install
   ```
2. Setup `.env` file with your environment variables.
3. Start the development server:
   ```bash
   npm run dev
   ```
API Docs added
## API Documentation
- GET /api/health: Check server status.
- POST /api/menu/analyze: Analyze food items with AI.
- POST /api/menu/optimize: Optimize menu pricing and descriptions.
- GET /api/menu/items: Get current menu items.
